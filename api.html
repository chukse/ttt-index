Endpoints

POST /v1/signup — free key; send {"email":"…"}
GET /v1/qbir — QBIR board. ?season= &limit=
GET /v1/qbir/{qb_id} — one quarterback
GET /v1/coaches — Coach Index. ?side=offense|defense
GET /v1/coaches/{name} — one coach (URL-encoded)
curl -H "Authorization: Bearer YOUR_KEY" \
